# Robotic Gripper 2 Assembly

This project presents a detailed CAD model and assembly of a **Robotic Gripper**, designed for precise object manipulation using dual servo motors. The gripper features symmetrical finger motion through a set of carefully designed linkages, making it suitable for robotic arms or automation platforms.

---

## ✨ Features

- Dual-finger, servo-driven actuation
- Compact mechanical design using levers and pivot pins
- Fully defined Bill of Materials (BOM)
- Exploded technical drawing included
- Uses industry-standard ISO fasteners

---

## ⚙️ Functionality

The gripper converts rotary motion from two servo motors into a synchronized gripping action using a combination of slider links, pivot joints, and connecting arms. The result is a compact and precise gripping mechanism capable of handling various part sizes.
