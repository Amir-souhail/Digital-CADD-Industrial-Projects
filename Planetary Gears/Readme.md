
# Planetary Gears Assembly

This project contains a complete 3D CAD model and technical documentation of a **Planetary Gear System**, developed using SolidWorks 2025. The design includes a central sun gear, multiple planet gears, a ring gear, and a carrier — assembled into a functional planetary gear train.

## 🔧 Project Components

The planetary gear system is composed of the following key parts:

| Item No. | Part Name         | Description                                 | Qty |
|----------|-------------------|---------------------------------------------|-----|
| 1        | Part4 Carrier      | Holds the planetary gears in place          | 1   |
| 2        | Shaft (ISO 15 ABB) | Axles for the planet gears                  | 3   |
| 3        | Part1 Ring Gear    | Internal gear (60T, 20PA)                   | 1   |
| 4        | Gear 2 Planet      | Planet gears (24T, 20PA)                    | 3   |
| 5        | Gear 3 Sun         | Central sun gear (12T, 20PA)                | 1   |

All gears follow ISO standard modules and pressure angles.

## 🎥 Motion Case Studies

This project explores three dynamic configurations of planetary gear kinematics:

1. **Case 1: Fixed Ring Gear**
   - **Input:** Sun Gear
   - **Output:** Carrier
   - Commonly used in automatic transmissions to multiply torque.

2. **Case 2: Fixed Carrier**
   - **Input:** Sun Gear
   - **Output:** Ring Gear
   - Results in high-speed output; often used in speed reduction systems.

3. **Case 3: Fixed Sun Gear**
   - **Input:** Ring Gear
   - **Output:** Carrier
   - Used when low-speed, high-torque output is desired.

Each motion case is demonstrated through animations included in this folder.
