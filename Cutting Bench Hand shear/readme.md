
# Cutting Bench Hand Assembly

## 📌 Overview

This project presents a **manually operated cutting tool** designed for bench-top applications. The mechanism uses a lever-operated blade system to perform shearing operations on soft materials. It is fully modeled in SOLIDWORKS with an emphasis on realistic mechanical motion and assembly constraints.

> ✅ This project was modeled **entirely from scratch** based on a reference video. No original technical drawings were provided.  
> 🛠️ All 2D and 3D CAD drawings were created by **Amir Souhail** through reverse engineering observation.

---

## 🔧 Key Features

- Lever-driven manual cutting mechanism
- Dual blade system for accurate shearing
- Bolt-mounted base for stable installation
- Designed for ergonomic use with a padded handle
- Built using standard ISO mechanical fasteners

## ⚙️ Working Principle

The user applies force through the long lever handle, rotating around the joint plate. This pushes the upper blade downwards, creating a shearing motion against the lower fixed blade. The mechanical advantage gained through the lever allows efficient cutting of sheet materials with minimal effort.
