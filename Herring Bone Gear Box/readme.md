# Herring Bone Gear Box Assembly

This repository contains the SolidWorks assembly files and documentation for a Herring Bone Gear Box, including part specifications, material requirements, and technical details.

## Parts List with Specifications

| Item No. | Part Name               | Suggested Material | Quantity | Critical Function |
|----------|-------------------------|--------------------|----------|-------------------|
| 1        | Gear Housing            | Aluminum 6061-T6   | 1        | Main structural component providing bearing support and alignment |

## Technical Specifications

- **Gear Ratio**: 1:1 (customizable in design)
- **Tooth Profile**: 30° herring bone angle
- **Operating Temperature**: -20°C to 120°C
- **Lubrication**: Synthetic gear oil (ISO VG 68)
- **Max Torque Capacity**: 85 Nm
- **Efficiency**: >98% at rated load

## Assembly Instructions

1. **Bearing Installation**:
   - Press-fit bearings into housing with 0.02mm interference
   - Maintain <0.01mm runout tolerance

2. **Gear Meshing**:
   - Set backlash to 0.05-0.08mm
   - Verify tooth contact pattern with Prussian blue

3. **Final Assembly**:
   - Torque M2 screws to 1.5 Nm in crisscross pattern
   - Apply thread locker to all fasteners
   - Fill with 120ml ISO VG 68 oil

## Design Features

- **Vibration Reduction**: Herring bone design eliminates axial thrust
- **Maintenance**: Includes inspection ports and magnetic drain plug
- **Modularity**: Housing designed for easy gear ratio changes
