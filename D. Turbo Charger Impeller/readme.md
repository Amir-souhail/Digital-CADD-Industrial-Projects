
# Turbo Charger Impeller

## 📌 Project Overview

This project presents a fully detailed CAD model and 2D technical drawing of a **Turbo Charger Impeller**, created as a precision design exercise. The impeller plays a critical role in forced induction systems by compressing air to boost engine power output. This model includes complex 3D geometry, rotational symmetry, and tight tolerances, ideal for showcasing high-speed component design in automotive and turbomachinery contexts.

> 🛠️ This project was created by reverse modeling from reference data and dimensional analysis, modeled fully in SOLIDWORKS.

---

## ⚙️ Purpose and Application

The impeller is a high-speed rotating component used in:

- **Turbochargers** – to compress intake air for internal combustion engines
- **Centrifugal Compressors** – as the primary air-moving element
- **Aerospace Turbomachinery** – where compact high-efficiency compressors are required

The impeller geometry directly influences air pressure, flow rate, and turbo efficiency.

---

## 🔧 Key Design Features

- **Radial and mixed flow vane design**
- **Precision radii and thickness transitions**
- **3D contoured profiles with symmetric rotation**
- **Tight dimensional tolerances for dynamic balance**
- **Multiple section views (A–A, D–D, E–E)** for detailed geometry breakdown

## 🧠 Engineering Concepts Demonstrated

- Rotational symmetry and axis-based modeling  
- Use of advanced fillets and surface blending  
- Integration of radial vane flow paths  
- Technical drawing interpretation with multiple section cuts  
- Reverse engineering and profile-based reconstruction
