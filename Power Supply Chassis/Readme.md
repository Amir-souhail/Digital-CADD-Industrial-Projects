# Power Supply Chassis Assembly

This repository contains the technical documentation and specifications for a Power Supply Chassis assembly.

## Parts List

| Item No. | Part Number | Suggested Material | Quantity | Critical Function |
|----------|-------------|--------------------|----------|-------------------|
| 1        | PART1       | Aluminum 5052-H32  | 1        | Main chassis frame providing structural support and heat dissipation |
| 2        | PART2       | Steel SECC (1.0mm) | 1        | EMI shielding cover for electrical interference protection |

## Technical Specifications

- **Dimensions**: Standard 1U rack-mountable form factor (44mm height)
- **Weight**: Approximately 1.2kg (fully assembled)
- **Finish**: Powder-coated black (RAL 9005) with conductive coating for grounding
- **Thermal Properties**: Designed for 300W heat dissipation capacity
- **Compliance**: Meets UL 60950-1 safety standards

## Design Features

1. **Structural Integrity**:
   - PART1 features reinforced mounting points for power components
   - Vibration-resistant construction for industrial environments

2. **Electrical Safety**:
   - PART2 provides complete Faraday cage protection
   - Integrated grounding points throughout chassis

3. **Thermal Management**:
   - Optimized airflow channels
   - Pre-drilled mounting points for cooling fans

## Assembly Instructions

1. Mount all power components to PART1 using provided isolation standoffs
2. Secure PART2 cover using M3 screws (torque to 0.6 Nm)
3. Verify continuity of all ground connections (<0.1Ω resistance)
