
# 🥫 Tin Opener Assembly

This repository contains the CAD assembly and detailed exploded view of a **Tin Opener**, designed and modeled by **Amir Souhail**, R&D Engineer in Autonomous Underwater Vehicles (La Spezia, Italy).

![Tin Opener Exploded View](./Tin%20Opener.JPG)

---

## 📄 Overview

The Tin Opener is a mechanical device designed for manual operation. This project includes:

- An exploded assembly drawing
- A complete Bill of Materials (BOM)
- Proper labeling of individual parts
- Standard fasteners and gears
- A mechanical lever system for cutting and rotating
