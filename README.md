# Digital-CADD-Industrial-Projects

This repository contains a collection of mechanical engineering design exercises and industrial part modeling projects created as part of advanced CAD training. Each project demonstrates solid modeling, assembly techniques, and drawing practices in software such as SOLIDWORKS.

## Purpose

The goal of this repository is to showcase and organize a set of industrially relevant mechanical projects, with detailed 3D models, assemblies, drawings, and supporting documentation. These projects reflect proficiency in mechanical design, modeling best practices, and drawing standards.

## Projects Included

- **Mechanical Gripper**  
  A CAD model of a mechanical gripper mechanism. The assembly includes multiple interlocking parts such as gripper arms, connectors, and actuation interfaces.  
  **Key Functions:**  
  - Converts rotational motion into gripping action.  
  - Can be actuated via servo or mechanical input.  
  - Demonstrates design for mechanical linkage systems.

- **PC Fan Assembly**  
  A detailed 3D model and drawing of a PC cooling fan with all key components: fan blades, motor, housing, and wire connections.  
  **Bill of Materials:**  
  - PART1_PC: Main fan frame  
  - PART2_PC: Motor mount cover  
  - PART3_PC: Fan blades  
  - PART4_PC WIRES: Electrical wiring  
  - PART5: Bearing shaft or similar element  
  - PART10_DCM: DC motor  
  - ISO 1224 – 170204: Standard hardware  
  **Main Function:**  
  Provides airflow for cooling applications in electronics using a brushless DC motor-driven fan.
