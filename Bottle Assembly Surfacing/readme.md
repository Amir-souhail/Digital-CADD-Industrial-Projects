# Bottle Assembly

## 📌 Project Overview

This project features a simple but effective **Bottle Assembly** modeled in CAD as part of the `Digital-CADD-Industrial-Projects` repository. The design consists of a base bottle and a two-piece cap system, showcasing basic modeling skills and mechanical fitment design. It serves as an introductory component for product design and consumer packaging studies.

---

## 🔧 Key Design Features

- **Threaded or snap-fit cap** system
- **Two-part cap** for sealing and aesthetics
- Compact and manufacturable design
- Designed with tolerance considerations for plastic parts
- CAD drawing includes multiple section views (A-A, B-B) and BOM

---

## 🧱 Material Suggestions

| Component | Material           | Notes                                  |
|-----------|--------------------|----------------------------------------|
| Bottle    | PET or HDPE        | Commonly used in food/beverage packaging |
| Cap 1     | Polypropylene (PP) | Good for sealing and chemical resistance |
| Cap 2     | ABS or PP          | Durable with smooth finish for branding |
