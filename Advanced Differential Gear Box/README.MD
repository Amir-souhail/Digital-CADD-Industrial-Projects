

# Advanced Differential Gear Box Assembly with Worm Gears

### 📌 Project Overview

This project features a reverse-engineered model of an **Advanced Differential Gear Box** using **worm gears** and a **helical configuration** for efficient torque transmission and speed control. It is an educational model created based on publicly available drawings and rebuilt in 3D CAD for learning and analysis purposes.

### ⚙️ Function and Working

The assembly works similarly to a differential gear box but uses worm gears instead of bevel or spur gears. Key features include:

* **Worm Drive Input**: High torque reduction with self-locking capability.
* **Helical Worm Gear Engagement**: Ensures smoother and quieter operation.
* **Differential Mechanism**: Spider gears allow for speed differences between two outputs.
* **Advanced Stability**: Tapered roller bearings improve load-handling and alignment.

---

### 🧠 Applications

This gearbox model can be used in:

* **Robotics**: Where precise torque control is essential.
* **Automotive Differential Systems**: Especially in electric or compact drive trains.
* **Heavy Machinery**: For angular drives where space and self-locking are advantages.
* **Educational Use**: A learning tool to demonstrate compound gear interaction.
